Scenario Descriptions & Behavioral Indicator Playbook
Category / Scenario Full Behavioral Description Primary Indicators (Strongest Drivers) Secondary / Co-Occurring Indicators
Scenario 1
WikiLeaks Exfiltration		 A user who did not previously use removable drives or work after hours suddenly begins logging in after hours, using a removable thumb drive, and uploading sensitive data to wikileaks.org, leaving the organization shortly thereafter. • WikiLeaks Access Count
• Thumb Drive / Removable Media Usage		 • After-hours activity (Evening/Night/Weekend)
• Sudden Departure Flag
Scenario 2
Pre-Departure IP Theft		 A user begins surfing external job websites and soliciting employment from a competitor. Before leaving the company, they use a thumb drive at markedly higher rates than their baseline to steal proprietary data. • Thumb Drive Usage Count (sharp spike above baseline)
• Job Site Access / Competitor Email Count		 • Sudden Departure Flag
• Elevated File / Http activity transitions
Scenario 3
Keylogger & Sabotage		 A disgruntled system administrator downloads a keylogger and uses a thumb drive to transfer it to their supervisor's machine. The next day, they use the collected credentials to log in as the supervisor and send out an alarming mass email causing organization-wide panic before leaving immediately. • Keylogger Download Count
• Mass Email Count (≥ 5 recipients)		 • Thumb Drive Usage Count (transferring keylogger)
• Unauthorized / Suspicious PC Login
• Sudden Departure Flag
Scenario 4
Lateral Snooping & Home Email		 A user repeatedly logs into another user's workstation, searches for interesting or confidential files, and emails them to their personal home email address (e.g., Gmail, Yahoo, Hotmail), with frequency escalating over time. • Unauthorized / Non-Primary PC Login
• Home Email Count		 • File Search / Decoy File Access Count
• Http → File or File → Http transitions
Mixed Mode
Multi-Vector Attack		 A compound threat profile in which a user exhibits behavioral indicators spanning two or more distinct insider scenarios within the same observation window (e.g., unauthorized PC snooping + home email exfiltration combined with WikiLeaks uploads or job-search USB theft). • Two or more primary threat indicators active simultaneously (e.g., WikiLeaks + Home Email or Unauthorized Login + Thumb Drive) • Multi-channel spikes across email, http, file, and after-hours timing
Benign Anomaly
Non-Malicious Outlier		 A legitimate employee whose daily reconstruction score crosses the MAD threshold due to an unusual but benign workload surge (e.g., deadline crunch, heavy email volume, atypical meeting gaps, or routine authorized USB use) with no malicious exfiltration or unauthorized access. • Routine Workload / Timing Spike (Morning/Afternoon count, inter-activity time, or Logon → Email) • Occasional authorized Thumb Drive or Weekend work without WikiLeaks, keyloggers, decoy files, or unauthorized logins
